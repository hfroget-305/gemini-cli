# Palette's Journal - UX/Accessibility Learnings

## 2026-03-21 - [Keyboard Shortcut Visibility]
**Learning:** Discoverability of powerful features like reverse history search (Ctrl+R) is significantly improved by including them in the primary UI-based help display, not just in external documentation.
**Action:** Always include high-utility keyboard shortcuts in the on-screen help component of terminal applications to reduce user friction and increase feature adoption.
